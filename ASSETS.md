# Asset provenance

Every asset in Isolith is one of three things: generated by a script in this
repository, hand-authored as source text, or a **CC0** pack vendored verbatim
with its provenance recorded here. Nothing is under a licence that requires
attribution, and nothing arrived without a recorded source.

This file is the complete record.

## Audio

Six clips, synthesised from first principles — sine partials, an exponential
percussive envelope, and a one-pole-filtered noise burst for the landing thud.
There are no samples, no recordings, and no external libraries; the generator
uses only the Python standard library (`math`, `wave`, `struct`, `random`).

```bash
python3 tools/generate_assets.py
```

| File | Description |
| --- | --- |
| `jump.wav` | Rising sweep, 320 → 660 Hz, 180 ms |
| `land.wav` | Filtered noise over a 180 → 70 Hz drop, 160 ms |
| `collect.wav` | Two-note chime, A5 then E6, 340 ms |
| `bounce.wav` | Wobbling 220 → 900 Hz launch sweep, 280 ms |
| `death.wav` | Detuned 520 → 130 Hz fall, 400 ms |
| `complete.wav` | A-major arpeggio, A4 C#5 E5 A5, 950 ms |

**Output is deterministic.** Each clip seeds its own RNG from its name, so
regenerating produces byte-identical files. CI regenerates them and fails the
build if anything differs, which catches both generator drift and hand-edited
WAVs.

## Third-party CC0 packs

Two things procedural generation does not beat: a real sky, and photogrammetry-
derived surface detail. Both sources are CC0 1.0 site-wide.

| Asset | Source | Used for |
| --- | --- | --- |
| `qwantani_dusk_1_puresky` (2K HDR) | [Poly Haven](https://polyhaven.com/a/qwantani_dusk_1_puresky) | Sky panorama and image-based ambient light |
| `Rock030` (1K JPG) | [ambientCG](https://ambientcg.com/view?id=Rock030) | Solid platforms |
| `Grass004` (1K JPG) | [ambientCG](https://ambientcg.com/view?id=Grass004) | Grass-topped platforms |
| `Concrete034` (1K JPG) | [ambientCG](https://ambientcg.com/view?id=Concrete034) | Crumbling platforms |

Fetched and verified by:

```bash
python3 tools/fetch_assets.py           # fetch, verifying against the lock
python3 tools/fetch_assets.py --check   # verify what is on disk
python3 tools/fetch_assets.py --update  # re-download and rewrite the lock
```

Every download is pinned by URL **and** SHA-256 in `tools/assets.lock.json`, so
a file changing under a stable URL is a hard failure rather than a silent swap.
Only the maps the renderer samples are extracted — displacement is the largest
file in each pack and goes unused, since the geometry is boxes. Extracted files
are byte-identical to what the source published; nothing is re-encoded.

Licence notices are written alongside the files, in
`assets/thirdparty/*/LICENSE.txt`.

### Where they are *not* used

Textures are applied only to neutral level geometry. Hazards, bounce pads, the
goal, shards, and checkpoints stay flat and emissive on purpose: they must be
identifiable at a glance from a fixed isometric distance, and photographic
detail works against that. See `src/Level/Palette.cs`.

The game runs without any of this. If `assets/thirdparty/` is absent, every
material falls back to its flat palette colour.

## Geometry

There are no mesh files, imported or otherwise. Levels are JSON
(`courses/*.json`) or procedurally generated, describing boxes,
and `CourseBuilder` turns them into `BoxMesh`/`BoxShape3D` pairs at load time.
Shards are a `PrismMesh`, checkpoints and the goal pad are `CylinderMesh`, and
the player is a `CapsuleMesh` with a small box for a snout.

This is a deliberate constraint rather than a placeholder: it keeps the
repository free of binary art, makes every level reviewable as a text diff, and
means the visual style is defined entirely by `Palette.cs`.

## Icon

`icon.svg` is hand-written SVG — an isometric cube drawn at the same projection
the in-game camera uses (45° yaw, `atan(1/√2)` pitch), so its three faces are
equally foreshortened. It is plain text and can be read in full in this
repository.

## If you add an asset

Anything new must be generated by a script here, hand-authored as source text,
or CC0/public-domain, fetched through `tools/fetch_assets.py` with a pinned
checksum, and recorded in the table above. Please do not
add assets under a licence requiring attribution without also adding the
attribution to this file.

CC0 sources that would satisfy this, and what adopting one would actually cost,
are surveyed in [`docs/ecosystem.md`](docs/ecosystem.md).

[cc0]: https://creativecommons.org/publicdomain/zero/1.0/
